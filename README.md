# Laboratorio interactivo de muerte celular

Aplicación web estática, 100% cliente, para que estudiantes construyan diagramas de seis vías: apoptosis intrínseca, apoptosis extrínseca, piroptosis, necroptosis, autofagia y PANoptosis.

## Publicación gratuita en GitHub Pages
1. Crear un repositorio público en GitHub (por ejemplo, `laboratorio-muerte-celular`).
2. Subir el archivo `index.html` en la raíz del repositorio (no es necesario subir las imágenes originales de las lecturas).
3. En **Settings → Pages → Build and deployment → Deploy from a branch**, elegir `main`, carpeta `/ (root)`, guardar.
4. Abrir el enlace `https://TU-USUARIO.github.io/laboratorio-muerte-celular/`.

## Uso en el aula
- Cada estudiante ingresa su nombre y elige una vía.
- Dibuja en el lienzo, inserta rótulos, flechas y redacta evidencia experimental.
- Descarga `Entrega_muerte_celular_Nombre.zip` y lo envía por el LMS o una carpeta de solicitud de archivos de OneDrive.

**Privacidad:** la app no recopila datos en un servidor ni envía datos a terceros. Usa localStorage para persistir el trabajo **solo en el navegador y dispositivo usados**. Los datos pueden borrarse al limpiar el navegador. No autentica al estudiante ni califica automáticamente. La subida a Microsoft 365/OneDrive no está automatizada.

## Referencia docente
Park et al. Diversity and complexity of cell death: a historical review. *Experimental & Molecular Medicine* 55, 1573–1594 (2023). DOI: 10.1038/s12276-023-01078-x.
